# My First CSS - Landing Page

A landing page built as part of [The Odin Project](https://www.theodinproject.com/) Foundations curriculum.

## Live Preview

[View the project here](https://mebaiashan.github.io/my-first-css/)

## About

This project is a responsive landing page designed from a reference image. It includes a hero section, an information section, a quote section, a call-to-action section, and a footer.

## What I Learned

- Using CSS Flexbox for layouts
- Styling buttons and navigation links
- Working with colors, spacing, and typography
- Organising CSS with comments and sections
- Using Git for version control and deploying with GitHub Pages

## Built With

- HTML5
- CSS3 (Flexbox)
